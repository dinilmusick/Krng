# Krng Key Ring & Encrypted Key Vault

Krng is the secure key vault system app that manages encrypted credentials, API key storage (`StoreKey`), retrieval (`RetrieveKey`), listing (`ListKeys`), and deletion (`DeleteKey`) for ecosystem apps.

## 🚀 How to Run

### Command to Start Krng Vault System:
```bash
# In the Krng directory:
node dist/Krng.js
```
Or with tsx:
```bash
npx tsx src/Krng.ts
```
Or via pnpm/npm:
```bash
npm start
```

---

## 🌐 Network Ports
- **Default Port**: `10091`
